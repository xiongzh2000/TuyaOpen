核心功能

🎙

AI 语音对话

长按说话，松手发送。支持流式 ASR + TTS，对话响应快速自然，支持多轮上下文。

🎨

AI 图片生成

语音描述即可生成图片，自动存入相册。支持上下滑动浏览，长按弹出删除和上传菜单。

👋

手势互动

内置 QMI8658 六轴 IMU，支持甩动、敲击、翻转三种手势，触发猫咪不同表情反应。

🚶

智能计步

动态阈值计步算法，自适应佩戴位置。Apple Watch 风格圆弧进度环，每日目标 1000 步。

☀

天气服务

接入涂鸦云天气 API，自动获取当前温度与天气状况，30 分钟自动刷新。

🐱

表情系统

卡通猫表情贯穿全场景：对话状态、手势响应、情绪反馈，让冰冷设备有温度。

📲

WiFi 传图

设备屏幕显示二维码，手机扫码打开上传页面，照片自动缩放为 466×466 JPEG 后通过局域网 HTTP 高速直传到相册。iOS / Android 通用，无需安装 App。

产品优势

1

全栈自研，深度整合

基于 TuyaOpen SDK 全栈开发，AI 服务、云端、固件、UI 深度整合，非简单方案拼凑。自定义 UI 框架完全掌控交互体验。

2

多模态 AI 交互

语音 + 图片生成 + 手势，三种交互通道融合。不只是"能说话的设备"，而是能看、能画、能感知动作的 AI 伴侣。

3

情感化设计

卡通猫表情系统让 AI 有"表情"，手势触发即时情绪反馈。将冷冰冰的可穿戴变成有温度的随身伙伴，提升用户粘性。

4

低成本量产方案

T5AI 单芯片集成 WiFi + AI 推理 + 音频编解码，BOM 成本可控。1.75 寸圆形 AMOLED 兼顾颜值与功耗，适合饰品化量产。

5

运动健康闭环

软件计步算法 + 动态阈值自适应，无需额外传感器。Apple Watch 风格进度环，直观展示运动目标，为健康场景打下基础。

6

跨平台可复用

核心 AI 组件（语音、图片、UI 框架）基于 TuyaOpen 组件模型，可快速移植到 T2/T3/ESP32 等平台，一套代码多产品复用。

硬件平台

主控芯片涂鸦 T5AI (BK7258) — 双核 ARM Cortex-M33, 内置 WiFi/BLE
开发板微雪 T5-E1 Touch AMOLED 1.75"
显示屏1.75 寸圆形 AMOLED, 466×466, QSPI 接口
触控CST9217 电容触控 (I2C)
运动传感器QMI8658 六轴 IMU — 加速度计 + 陀螺仪 (I2C)
音频板载麦克风 + 扬声器，Opus 编解码
连接WiFi 2.4GHz，涂鸦云 MQTT + AI Agent 服务

软件架构

Application Layer
├── app_badge_ui.c    三页滑动 UI (LVGL v9)
├── app_chat_bot.c    AI 对话入口 + 手势映射
├── app_gesture.c     手势检测 + 计步算法
├── app_qmi8658.c     IMU 驱动 (I2C)
└── cat_faces.c       猫表情图片资源

AI Components (TuyaOpen)
├── ai_mode_hold      长按说话模式状态机
├── ai_audio_input    麦克风采集 + VAD
├── ai_audio_player   TTS 播放
├── ai_picture        图片生成 + 相册 + WiFi 传图
└── ai_ui_manage      UI 消息分发框架

SDK / Platform
├── tuya_ai_agent     AI Agent 云端通信
├── file_storage      云文件下载 (MQTT + HTTPS)
├── tuya_weather      天气数据服务
├── TAL (OS 抽象层)   线程 / 定时器 / I2C / 内存
└── T5AI Platform     BK7258 BSP + 工具链
