# 图生图（Image-to-Image）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 your_chat_bot 打印机固件的 Wechat UI "+"弹窗中新增"图生图"入口，支持摄像头拍照或相册选图，图片加入输入队列后用户用现有语音机制发出编辑指令，AI 改图后自动打印。

**Architecture:** 底层管道已存在（`ai_mode_hold_vad_change` 在语音 VAD 起时自动把 `ai_picture_input` 队列里的图先发给 AI），只需在 UI 层加"图生图"弹窗入口，在 App 层处理两个新 Action，把图片加入队列并给用户提示。打印链路零改动。

**Tech Stack:** C，LVGL v8/v9，TuyaOpen TAL API，`ai_picture_input`/`ai_video` 组件
