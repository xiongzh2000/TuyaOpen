三种状态页面

三、功能亮点

极速压秒级端到端出图

自部署 Flux.2-Keltin-4B 开源模型，A10 GPU 推理 320×480 仅 0.8~0.9 秒。松手到上屏体验 2 秒，远超市面同类产品 5~10 秒的等待体验。

自主开源模型自部署

使用开源 Flux.2-Keltin-4B（4B 参数蒸馏版），自建 A10 集群部署推理服务。模型可控、不依赖第三方 API、持续优化空间大。

极简3 页 UI 零学习成本

只有 3 种状态页面（待机 / 聆听 / 生成中），无需触屏操作、无需翻页、无需确认弹窗。老人儿童均可立即上手。

自动生图即打印

图片生成后自动触发热敏打印，无需额外确认。图片同步全屏展示 + 打印输出，"说完就出纸"。

快打2~3 秒打印出纸

DP-48A 热敏打印机优化至 115200 波特率 + ESC/POS 分块发送。从接收图片到完整出纸仅 2~3 秒，告别漫长等待。

居中智能打印居中

320 像素图片在 384 dots 打印头上自动居中（偏移 32 dots），输出美观不偏左。JPEG 解码 → 灰度抖动降噪 → 位图发送全链路优化。

6"生成中"状态不触发ai_chat_ui.c 缺少 AI_MODE_STATE_THINK case补全 THINK 状态消息分发

六、已验证的扩展能力

简化版打印机基于 TuyaOpen SDK 的共享 ai_components 组件库开发，底层能力已全面验证。通过 Kconfig 配置开关即可组合出不同版本的打印机产品。

已验证AI 语音对话

连续对话、语音打断、流式文字显示、唤醒词免按键触发。支持 hold / oneshot / wakeup / free 四种交互模式。

已验证拍照打印

摄像头拍照 → 保存到本地相册 → 选择打印。支持 YUV 帧采集 + JPEG 编码 + 热敏输出。

已验证图片 AI 特效打印

拍照或从相册选图 + 语音指令（如"变成卡通风格"），AI 图生图改图后自动打印。同 session 图文联合输入。

已验证多模态识图

摄像头拍照 → AI 识物/识字/讲解。可用于"拍题打答案"、"拍物讲故事"等教育场景。
